🎬 Movie Bro
A MERN stack movie recommendation platform where users can browse 25 Telugu movies, search by title or genre, and filter by release year. The homepage showcases rectangular movie cards that reveal full details — including genre, year, description, rating, and OTT platforms — when hovered over. Users can also view a dedicated movie detail page for in-depth information.

Live->https://moviebro-frontend.vercel.app/

Note : For Backend check for moviebro-backend in my git repos.

Features

🔍 Search and filter movies by title, genre, and release year
🖼 Rectangular movie cards with hover overlay effects
📄 Detailed movie pages with complete information
⚡ Responsive and modern UI design
📤 Static poster hosting from the backend

Tech Stack

Frontend: React, CSS

Backend: Node.js, Express

Database: MongoDB

Deployment: Vercel (frontend) & Render (backend)
